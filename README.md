# claude-first

Small browser games, each a single self-contained HTML file. Open a file in any browser to play.

| File | Game |
| --- | --- |
| `snake.html` | Pocket Snake: arrow keys / WASD to steer, Space to pause, swipe or on-screen pad on touch devices |
| `Tic-Tac-Toe.html` | Tic-Tac-Toe |
| `slipstream.html` | Slipstream: top-down circuit race, arrow keys / WASD to drive, Space to brake, P to pause, R to restart, on-screen wheel and pedals on touch devices |
